## 🧑‍💻 Sobre mim

Meu nome é **Ailton**, mas sou conhecido como **Sniper FPS** no Discord.

Trabalho no desenvolvimento de bots personalizados para Discord, utilizando principalmente **Python** e a biblioteca **discord.py**.

Meu objetivo é transformar ideias em sistemas funcionais, criando ferramentas que facilitam a administração, a organização e a interação dentro de servidores.

Também sou o criador da **Luna**, bot oficial do projeto **Lan House Gamer For Discord**.
